The server is configured entirely through environment variables, set in your MCP client's config or your shell environment.

## Environment variables

| Variable | Required | Default | Description |
| --- | --- | --- | --- |
| `YELLOW_PRO_BASE_URL` | No | selected by `YELLOW_PRO_SANDBOX` | Explicit REST base URL override |
| `YELLOW_PRO_SANDBOX` | No | `false` | Exactly `true` uses staging; otherwise production |
| `YELLOW_PRO_API_KEY` | Private tools | — | API key |
| `YELLOW_PRO_API_SECRET` | Private tools | — | API secret (HMAC-SHA256) |
| `YELLOW_PRO_APP_SESSION_ID` | Private tools | — | App session id (`uid` credential) |
| `YELLOW_PRO_ENABLE_TRADING` | No | off | Exactly `true` to enable trading tools/commands |
| `YELLOW_PRO_MODULES` | No | all | Comma list of `market,account,trading` to filter tools |
| `YELLOW_PRO_RATE_LIMIT_MS` | No | `100` | Minimum gap between requests, in milliseconds |

## Environments

By default the server talks to production at `https://trade.api.yellow.pro`. Setting `YELLOW_PRO_SANDBOX=true` switches to staging at `https://api.staging.yellow.pro.neodax.app`. An explicit `YELLOW_PRO_BASE_URL` takes precedence over sandbox mode.

<Warning>
Credentials are environment-specific. Keys created for staging (`YELLOW_PRO_SANDBOX=true`) do not work on production, and vice versa.
</Warning>

## Credentials

Market data tools work without any credentials. Private tools — anything touching account state or trading — require all three of `YELLOW_PRO_API_KEY`, `YELLOW_PRO_API_SECRET`, and `YELLOW_PRO_APP_SESSION_ID`.

## Enabling trading

Trading tools are **not registered** unless `YELLOW_PRO_ENABLE_TRADING=true`. This is a deliberate safety default.

<Warning>
Do not work around a disabled-trading state by calling the REST API directly. The opt-in flag exists so that order placement is a conscious choice.
</Warning>

## Module filtering

Use `YELLOW_PRO_MODULES` to load only the tool groups you need. For example, `YELLOW_PRO_MODULES=market,account` exposes market data and account tools but omits trading entirely. See [Tools](/mcp/tools) for what each module contains.
